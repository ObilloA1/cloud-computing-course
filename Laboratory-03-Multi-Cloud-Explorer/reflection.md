# Mission Reflection

The cloud platform that impressed me the most was Amazon Web Services (AWS). I was impressed by the large number of services available and how AWS can support different types of organizations, from startups to large enterprises. AWS provides services for computing, storage, databases, networking, security, artificial intelligence, and many other areas. Learning about AWS helped me understand why it is widely used for different cloud computing requirements.

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide cloud-based computing, storage, databases, networking, security, identity management, and scalability. They also provide management consoles that allow users to create, monitor, and manage cloud resources. Another important similarity is that all three platforms support Linux and Windows workloads and provide services for modern application development.

Business requirements strongly influence cloud platform selection. A company should consider its budget, existing technologies, workload requirements, security needs, geographic requirements, scalability, and technical expertise. For example, a university that already depends heavily on Microsoft products may benefit more from Azure, while an AI research company may prefer Google Cloud because of its AI and machine learning capabilities.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The correct decision depends on matching the customer's requirements with the strengths and services of each provider. I also learned how important scalability, reliability, integration, and cost can be when making a cloud recommendation.

My GitHub Cloud Computing Portfolio has improved because I now have organized documentation about multiple cloud platforms. I learned how to research official cloud documentation, compare equivalent services, analyze business scenarios, and document Linux server information. This activity also improved my understanding of how cloud computing can solve real-world business problems.
